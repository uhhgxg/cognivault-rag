## 当前实现范围

- 多格式文档加载、去重、分块、元数据增强和多模态处理；
- Dense + BM25 稀疏检索 + RRF 融合 + Rerank 的混合检索链路；
- 基于 LangGraph 的意图识别、查询处理、检索、工具调用和回答生成；
- 会话记忆、长期记忆、归档和消息回滚；
- MCP Server、FastAPI 后端、Streamlit 可观测面板和 RAG 评测；
- 单元测试、集成测试、E2E 测试及基准评测脚本。

## 复现与验证

```powershell
python -m pytest -m "not llm and not e2e"
python -m compileall src
```

需要真实模型、数据库或外部服务的测试，应在配置好 `.env` 后按测试标记单独执行。

项目的公开品牌为 Cognivault；现有 `src/ragent_backend` 包路径和 `RAGENT_*` 环境变量暂时保留，以保证已有启动脚本和配置兼容。后续若需要彻底迁移内部命名，应单独做一次带回归测试的重构。
